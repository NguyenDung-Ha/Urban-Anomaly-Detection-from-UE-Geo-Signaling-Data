# Data

## Public sample

[`sample/geo_signaling_public_sample.xlsx`](./sample/geo_signaling_public_sample.xlsx) is a small anonymized sample that illustrates the GEO-signaling schema and field semantics. It is not the full experimental dataset and is not intended to reproduce the reported aggregate counts by itself.

## Private source data

The original operator feed is not included in this public repository. In particular, `datafeed.20251221-0300.csv.gz` remains private because it is subject to operator-confidentiality and mobility-privacy requirements.

Access may be considered for IEEE reviewers only after a formal request, operator approval, and application of appropriate secure-access controls.
