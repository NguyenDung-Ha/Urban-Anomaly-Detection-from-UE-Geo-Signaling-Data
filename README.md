# Supplementary Material

Supplementary material for the paper:

**Urban Anomaly Detection from UE Geo-Signaling Data**

Authors: Nguyen-Dung Ha, Minh-Hoang Nguyen, and Vu-Duc Ngo.

[View the supplementary material](./1571313031_Supplementary_Material.pdf)

The document provides:

- Top-10 area-event and user-movement validation;
- shared-baseline versus leave-one-date-out benchmarking;
- Top-k comparison with statistical and machine-learning baselines;
- LTE CellTrace and GEO-location system characterization;
- observation-frequency and location-quality metadata distributions;
- implementation, quality-control, and privacy details.

## Data availability

Only aggregated and anonymized statistics are reported. Subscriber-level
GEO records are not publicly released because of operator confidentiality
and mobility-privacy requirements.
